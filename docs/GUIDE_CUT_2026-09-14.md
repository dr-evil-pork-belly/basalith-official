# Guide surface cut, September 14, 2026

Decision: Basalith will not sell through independent contractors, at launch or
later. The public site described a Legacy Guide network that did not exist and
carried a recruiting page, a recruiting intake, and a role title on every
delivery reference. All of it is gone from public copy. The gated Guide portal
(`/archivist/*`, `/guide-onboard`, `proxy.ts`) is untouched; it is internal
tooling, not copy.

Companion strategy doc in the project: `claude/BASALITH_GTM_LAUNCH_STRATEGY_2026-09-14.md`.

Eighteen files changed, all on disk, none committed. Full unified diff at
`docs/GUIDE_CUT_2026-09-14.diff`. Every changed file passes a TypeScript syntax
parse. No em dashes or exclamation points were introduced. Nothing was deployed.
The working tree was on `main` at `8c643ca` when the files were written, so
branch before committing:

    git checkout -b guide-cut-2026-09-14
    git add -A
    git commit -m "Retire the Legacy Guide recruiting surface; founder-led delivery copy"
    vercel            # preview, read it in a private window
    # merge to main and push only when you are ready to ship: push to main deploys

## Cut outright (the recruiting surface)

### /join-archivists

Whole page replaced with `permanentRedirect('/contact')` (308). The layout no
longer carries the "Become a Legacy Guide" title. The URL is kept so held links
do not 404; it should never be reused, since it carries the retired word. The
directory can be deleted after the redirect has lived a few months.

### /about, section 4

Was "The Legacy Guides" / "The people who make this real." with "Every archive is
opened by a Legacy Guide, a trained person who runs the Founding Session and
stays with the archive as it grows." That described a network of trained people.
There is one Guide, a friend, and every session to date has been run by you.

Now "Who runs it" / "Every archive is opened in person." with "The founder of
Basalith runs every Founding Session today. One person in the room, listening to
how the operator decides, and staying with the archive as it grows." Second line
is "The technology handles the complexity. A person handles the rest." The
closing italic line is unchanged.

**Confirm:** "runs every Founding Session today" is written as true. If your
friend has run one, change it before promoting. And the day anyone other than
you runs a session, this section and the two founder lines below change with it.

### /contact intent

"Becoming a Legacy Guide" became "Partnering as an advisor (CPA, exit planner,
attorney)". The stored value is still `partner`, so `/api/contact` and the
`contact_requests.intent` column are untouched. This is the partner door the
strategy calls for, opened in the same slot the recruiting door used.

### /apply referral source

"Referred by a Legacy Guide" removed. "Referred by an attorney or advisor" became
"Referred by my CPA, attorney, or advisor". The field is free text stored as
given (`archive_applications.referral_source`), no whitelist in the API, so
existing rows are unaffected and new rows start carrying the advisor signal.

### /apply copy and the admin notification

Three "a Legacy Guide will contact you within 48 hours" lines are now "we will
contact you within 48 hours" (success state for business and personal, the
business intro paragraph). The `/apply` meta description says "We reply within
48 hours." The internal notification email's next-step line was "approve and
assign a Legacy Guide" and is now "approve and schedule the Founding Session."
That email goes to you only.

## Addendum, same branch: milestone ladder contrast on /founding-session

Found from a phone screenshot after the preview went up. Stages 02 through 04
of the four-stage ladder rendered as dark grey text on a mid-grey card.

Cause, in `app/components/MilestoneProgress.tsx`. The component is a
progress widget: `currentDeposits` (default 0) marks stage 01 `active` and
stages 02 through 04 `locked`. The locked branch reached for the site's theme
tokens, and on this site the root tokens are the light marketing palette:
`--color-surface` is `#FFFFFF`, `--color-text-muted` is `#6A6660`. The page
places the ladder inside a void band, so the locked cards painted a white card
with dark grey text onto black and then set `opacity: 0.45` on the whole card.
Measured against `#0A0908`: locked body text landed at 2.85:1 and the deposit
line at 2.06:1. The active card's body text was `#6A6660` on void at 3.49:1,
which the contrast table in `globals.css` already lists under NEVER USE.

Fix. Every color in the component is now a dark-background value, hardcoded,
because the component draws its own dark card and must not inherit the light
palette. Gold `#C4A24A` (8.16:1), names at 0.9 alpha (15.09:1), body at 0.62
(7.36:1), the deposit line at 0.55 (5.94:1). Locked stages are no longer
ghosted; they get a plain dark card while reached and active stages keep the
gold tint and border, so the progression still reads without hiding the copy.
Mono labels were raised from 6.4 to 8 px up to 8.3 to 10 px; the smallest was
under the size anyone on a tablet can read. Status logic and the
`currentDeposits` prop are unchanged. Only `/founding-session` imports the
component.

One file changed: `app/components/MilestoneProgress.tsx`. Rendered
before-and-after: `docs/milestone-before-after.png`.
